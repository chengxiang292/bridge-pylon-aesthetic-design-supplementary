# Supplementary materials

Supporting documentation and data for LLM-assisted bridge-pylon aesthetic design.

| File | Contents |
| --- | --- |
| [Supplementary_Material_EN.docx](Supplementary_Material_EN.docx) | LLM comparison, pylon samples and scores, and reward-model classification and calibration results. |
| [Human_Survey_English.xlsx](Human_Survey_English.xlsx) | Questionnaire, participant information, and responses for ten design cases. |
| [SURVEY_SCREENING.md](SURVEY_SCREENING.md) | Screening rules and the 50-participant analysis cohort. |
| [External_Validation_15_Pylons.md](External_Validation_15_Pylons.md) | Additional aesthetic-network evaluation on 15 human-rated pylons. |

The survey workbook preserves all **56 collected responses**. The manuscript analysis uses **50 retained participants**, as documented in the screening file.

The human-rated samples used for the LLM comparison and external network evaluation come from Ref. [32]; the ten-case survey is a separate evaluation of optimized designs.

**Ref. [32]:** Xiang C, Chen A, Wang D, Ning Y. Deep-learning-based aesthetic evaluation network for bridge pylon and aesthetics-oriented bridge design. *Structures*. 2025;71:108167.
